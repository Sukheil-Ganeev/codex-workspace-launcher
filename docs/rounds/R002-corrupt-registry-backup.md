# R002 — битый registry.json не стирается молча

## Проблема

`Registry._load` ловил `JSONDecodeError` и молча стартовал с пустым реестром:
при следующем `save()` битый файл перезаписывался пустым — все зарегистрированные
проекты и кэш проб исчезали без следа.

## Сделано

При битом JSON файл переименовывается в `registry.json.corrupt` (рядом), в
stderr — предупреждение с путём; реестр стартует пустым, но исходник сохранён.

## Проверка

- `tests/test_launcher.py`: +2 проверки (reset данных; `.corrupt`-файл существует).
- RED подтверждён на старом коде; полный ран — 49 passed.
