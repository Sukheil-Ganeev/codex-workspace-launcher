# R053 — архивные проекты недоступны через точный ID

## Цель

Считать архивный проект отсутствующим при поиске по любому ID: полному или
короткому.

## Проблема

`Registry.get` исключает архивные строки из поиска по префиксу, но немедленно
возвращает результат точного поиска, даже когда у него `archived: true`.
Команды `open`, `doctor` и `rename` используют `get`, поэтому удалённый из
активного списка проект остаётся доступен по полному ID.

## Сделано

Добавлен регрессионный тест после архивации. Проверка активности применяется
одинаково к точному совпадению и к поиску по префиксу.

## Проверка

- До исправления targeted-проверка упала: точный ID возвращал архивную строку.
- После исправления `archived project is absent by full id` — `ok`; общий
  offline-набор — `55 passed, 0 failed` (HTTP picker-тест исключён).
- `python3 -m py_compile cwl/tools.py cwl/registry.py tests/test_launcher.py` —
  код 0; `git diff --check` — код 0.
- Полный `python3 -m unittest discover -s tests` остановился на создании
  HTTP-сокета для `test_picker_server`: `PermissionError: [Errno 1] Operation
  not permitted`. Детали — в корневом `OUT.md`.
