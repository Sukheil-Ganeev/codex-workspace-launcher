# R033 — пустой ID не должен совпадать с проектом

## Цель

Отклонять пустой идентификатор проекта, не интерпретируя его как префикс.

## Проблема

`Registry.get` поддерживает короткий поиск по префиксу. В Python любая строка
начинается с пустой строки, поэтому при единственном активном проекте вызов
`get("")` возвращает этот проект вместо `None`. Команды изменения проекта и API
picker могут получить действующий объект из отсутствующего ID.

## Сделано

Добавлена проверка одного активного проекта: пустой ID не должен находить его.
Правка прекращает поиск по префиксу для пустого значения; поиск непустых коротких
ID остаётся без изменений.

## Проверка

- До правки targeted-проверка завершилась `FAIL empty id does not match the only
  project` на реестре с одним проектом.
- После правки итоговый офлайн-набор — `53 passed, 0 failed`.
- `python3 -m py_compile cwl/picker.py cwl/registry.py tests/test_launcher.py` —
  код 0; `git diff --check` — код 0.
- Полный `unittest discover` заблокирован sandbox при создании localhost socket
  в HTTP picker-тесте (`PermissionError: [Errno 1] Operation not permitted`).
