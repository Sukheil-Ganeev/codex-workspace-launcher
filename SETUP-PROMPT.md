# Промт для Codex — настройка Codex Workspace Launcher с нуля

> Скопируй текст ниже (всё, что в кавычках) и вставь его в Codex.
> Codex сам всё установит и настроит. Работает на macOS, Linux и Windows.

```
Ты — системный инженер. Настрой мне "Codex Workspace Launcher" на этой машине.

ЦЕЛЬ: чтобы я мог быстро выбрать проект и открыть в нём нужный AI-инструмент
(Codex, Claude, Muse, Qwen и т.д.). Это простая программа на Python (один файл
launcher.py), которая показывает список моих проектов и запускает выбранный
инструмент в папке проекта.

ВАЖНО:
- У меня свои подписки/логины для инструментов. Их не запрашивай и не сохраняй.
- Никаких секретов, токенов, ключей и паролей не записывай в файлы проекта
  и не выводи в отчёт. Это публичный репозиторий.
- Определи ОС сам (macOS / Linux / Windows) и используй её штатные способы.

ШАГИ (по порядку):

1. Определи ОС. Проверь, что установлен Python 3.8+ (python3 --version).
   Если нет — установи штатным способом
   (macOS: brew install python; Linux: apt/dnf; Windows: python.org).

2. Прочитай файл launcher.py из этого репозитория. Не меняй его без
   необходимости.

3. Установи команду "codex-workspace":
   - macOS:   bash install/macos-install.sh
   - Linux:   bash install/linux-install.sh
   - Windows: install\windows-install.bat
   Убедись, что команда доступна (codex-workspace --help или
   python3 launcher.py list).

4. Настрой список проектов. Спроси меня, какие папки считаются проектами,
   или попроси задать переменную CODEX_WORKSPACE_ROOTS (родительская папка
   или список папок через двоеточие/точку с запятой). Добавь их командой
   `codex-workspace add <путь> --label "Имя"` или через переменную окружения.

5. Проверь, какие AI-инструменты уже установлены:
   `codex-workspace list` и `python3 launcher.py list`.
   Если какого-то инструмента нет, а я им пользуюсь — скажи мне, как его
   установить, но сам ничего не устанавливай без моей команды.

6. Сделай безопасный тест без открытия окна: убедись, что `launcher.py list`
   работает и показывает проекты без ошибок. Интерактивный picker и окна
   в тесте не открывай.

7. В конце дай короткий отчёт (по-русски, простыми словами):
   - что установлено и работает;
   - как я запускаю выбор проекта (команда или ярлык);
   - как добавить новый проект;
   - какой инструмент не найден и почему.

ПРАВИЛА КАЧЕСТВА:
- Не меняй и не удаляй существующие файлы проекта без причины.
- Действуй минимально и безопасно, без лишних файлов.
- Ничего не публикуй и не отправляй наружу без моей команды.
```
