# Codex Workspace Launcher

Выбери проект — и нужный AI-инструмент (Codex, Claude, Muse, Qwen и другие)
откроется сразу в папке этого проекта. Работает на **macOS, Linux и Windows**.

Без зависимостей: только Python 3 и стандартная библиотека.

## Как это работает

1. Ты запускаешь команду `codex-workspace pick` (или двойной клик по ярлыку
   на macOS).
2. Появляется список твоих проектов (папок).
3. Ты выбираешь проект → лаунчер открывает выбранный AI-инструмент в этой
   папке, в терминале.

Проекты хранятся в маленьком файле у тебя на компьютере. Никакие личные
данные никуда не отправляются.

## Установка

| Система | Команда |
|---------|---------|
| macOS   | `bash install/macos-install.sh` |
| Linux   | `bash install/linux-install.sh` |
| Windows | двойной клик по `install\windows-install.bat` |

Или просто запусти вручную:

```bash
python3 launcher.py pick
```

## Использование

```bash
codex-workspace pick                              # интерактивный выбор
codex-workspace list                              # список проектов
codex-workspace add /путь/к/проекту --label "Имя" # добавить проект
codex-workspace open <id> --tool claude           # открыть напрямую
```

### Автоподхват проектов

Можно не добавлять проекты по одному, а указать родительскую папку — лаунчер
сам найдёт подпапки:

```bash
export CODEX_WORKSPACE_ROOTS=/Users/you/projects:/Users/you/work
```

## Инструменты (определяются автоматически)

Codex, Claude, Muse, Qwen, Grok, OpenCode, Gemini, GitHub Copilot.
Если инструмент установлен и есть в PATH — он появится как доступный.

## Режимы запуска

- `safe` — обычный запуск;
- `free` — без песочницы, но с подтверждениями;
- `yolo` — полные права без подтверждений (осторожно).

Выбор режима: `codex-workspace open <id> --mode safe|free|yolo`.

## Настройка с нуля через Codex

Хочешь, чтобы всё поставил Codex автоматически? Открой
[`SETUP-PROMPT.md`](SETUP-PROMPT.md) и вставь готовый промт в Codex.

## Структура

```
launcher.py        — вся программа (реестр, инструменты, пикер, запуск)
install/           — установка под macOS / Linux / Windows
SETUP-PROMPT.md    — промт для Codex
```

## Безопасность

- Программа не хранит и не запрашивает логины, пароли, токены и ключи.
- Реестр проектов — это только пути к папкам у тебя на машине.
- Не добавляй в репозиторий файлы с секретами (`.env`, ключи, токены).
