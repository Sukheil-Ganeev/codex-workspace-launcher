# R043 — кэш проверки инструмента должен совпадать с запрошенным ID

## Цель

Не позволять записи кэша одного инструмента становиться результатом проверки
другого инструмента.

## Проблема

`probe_tool` возвращает переданную запись кэша без сравнения её `id` с ID
определения инструмента. Если запись реестра содержит чужой ID, каталог может
показать неверный инструмент и использовать его данные при подготовке запуска.

## Сделано

Добавлен регрессионный тест на несовпадающий ID. Такая запись кэша теперь
игнорируется, и выполняется обычная проверка определения.

  `ToolReport(id='other-tool', state='ready')` вместо повторной проверки.
