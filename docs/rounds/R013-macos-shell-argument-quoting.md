# R013 — аргументы macOS launch plan передаются буквально

## Цель

Сохранить каждый аргумент запуска macOS как отдельное буквальное значение при
передаче через временный `.command`-скрипт.

## Проблема

`_macos_terminal_plan` заключает путь проекта и исполняемый файл в shell-кавычки,
но добавляет аргументы через обычный `join`. Аргумент с пробелом распадается на
несколько значений; shell-конструкции вроде `$(...)` или `;` могут выполниться
вместо передачи текста программе.

## Сделано

Добавлен регрессионный тест, который запускает сгенерированный скрипт с
аргументами, содержащими пробел и `$(...)`. Каждый аргумент экранируется тем же
shell-quoting helper, что уже используется для пути и исполняемого файла.

## Проверка

- До исправления: регрессионный тест должен обнаружить изменённый аргумент и
  созданный shell-командой маркер.
- После исправления: аргументы должны совпасть побайтно по значениям, маркер не
  должен появиться; touched suite и `py_compile` должны пройти.
