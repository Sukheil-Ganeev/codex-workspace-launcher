# R073 — повреждённая дата проверки не должна ломать кэш инструментов

## Цель

Если поле `checked_at` в сохранённом кэше проверки инструмента отсутствует,
имеет неверный тип/значение, не является конечным числом или находится в
будущем, считать кэш просроченным и выполнить обычную проверку инструмента.

## Проблема

`Registry.get_probe` без проверки вызывает `float(checked_at)`. Строка или `null`
из корректного JSON поднимает исключение и может прервать сбор списка
инструментов/пикера. `NaN` и будущая метка времени, напротив, могут обходить
сравнение TTL и оставлять устаревший кэш пригодным.

## Сделано

Отклоняются нечисловые, не конечные и будущие метки времени; такие записи кэша
возвращают `None`, чтобы вызывающий код мог перепроверить инструмент. Добавлен
регрессионный тест на повреждённую метку времени.

## Проверка

  будущего вернули кэш; отдельная проверка также поймала переполнение на очень
  большом целом.
- После исправления: `REGISTRY: 23 passed, 0 failed`; офлайн-набор без HTTP
  picker — `OFFLINE GATES: 61 passed, 0 failed`.
