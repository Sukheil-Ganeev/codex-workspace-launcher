# R023 — CLI picker показывает только готовые инструменты

## Цель

Не предлагать в терминальном picker инструменты, которые уже определены как
недоступные на этой машине.

## Проблема

`run_cli_picker` вычисляет список готовых инструментов, но строит меню из полного
списка. Поэтому недоступный инструмент выглядит выбираемым, а ошибка обнаруживается
только после выбора и проверки рабочего пространства.

## Сделано

Проверка фиксирует, что меню инструментов содержит только готовые варианты.
Минимальная правка использует уже вычисленный список готовых инструментов; если
готовых вариантов нет, picker сообщает об этом и завершает работу без меню запуска.

## Проверка

- До правки targeted-проверка дала `FAIL` для меню с недоступным инструментом и
  для случая без готовых инструментов.
- В итоговом офлайн-наборе, без HTTP picker-теста, — `53 passed, 0 failed`.
- `python3 -m py_compile cwl/picker.py cwl/registry.py tests/test_launcher.py` —
  код 0; `git diff --check` — код 0.
- `python3 -m unittest discover -s tests` не проходит из-за
  `PermissionError: [Errno 1] Operation not permitted` при создании localhost
  socket в `test_picker_server`.
